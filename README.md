Ressourcenpaket für den GGG-Minecraft-Server (Paper 26.3).

| Version | Datei | SHA-1 | Inhalt |
|---|---|---|---|
| v1 | `ggg-ressourcenpaket-v1.zip` | `04443e4211e6fccdd92230f24f3e7037f82fb9ff` | BetterModel (Flugmounts, Bosse) + MMOMagic (Zauberstäbe, Schmuck, Roben, Rucksäcke) |

Download-Link für `server.properties`:
`https://raw.githubusercontent.com/achondis/ggg-server/ressourcenpaket/ggg-ressourcenpaket-v1.zip`

Bei Änderungen eine neue Datei mit höherer Versionsnummer anlegen (v2, v3, …) und Link + SHA-1
in `server.properties` anpassen – sonst behalten Spieler die alte Version im Cache.
