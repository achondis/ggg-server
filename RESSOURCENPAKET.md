# Ressourcenpaket

`resourcepack.zip` ist das von BetterModel erzeugte Ressourcenpaket (Flugmounts und Dungeon-Bosse).

Eintrag in `server.properties`:

```
resource-pack=https://raw.githubusercontent.com/achondis/ggg-server/resourcepack/resourcepack.zip
resource-pack-sha1=a1dad68652d6893c699f466943a3064b27debeec
require-resource-pack=true
```

Bei jeder Änderung am Paket muss `resource-pack-sha1` neu berechnet werden.
