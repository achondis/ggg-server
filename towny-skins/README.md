# Towny-Skins

Skins (64x64, klassisches Modell) für die Figuren des Towny-Plugins:

| Datei | Figur |
|---|---|
| `Pestti-Skin.png` | Stadtwache Pestti (Wachturm) |
| `Farmer-Skin.png` | Farmer (Farm) |
| `Holzfaeller-Skin.png` | Holzfäller (Holzfällerhütte) |
| `Schmied-Skin.png` | Schmied (Schmiede) |
| `Os-Skin.png` | Koch Os (Großküche) |

Für Minecraft müssen die Skins von Mojang signiert sein: Raw-Link der Datei auf https://mineskin.org eingeben,
"Texture Value" und "Texture Signature" in die `config.yml` von Towny eintragen (`wache.skin` bzw. `arbeiter.skins.*`).
